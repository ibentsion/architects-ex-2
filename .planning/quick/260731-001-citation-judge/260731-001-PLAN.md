# Quick Task 260731-001 — LLM-judged citation accuracy

Replace the deterministic citation matcher with an LLM judge that reads the
**actual cited corpus pages** and decides whether they establish the
ground-truth answer.

## Definition being implemented

> Citation accuracy — does the cited evidence actually establish the answer?
> Resolve each cited {file, page} to the actual corpus page and use an LLM
> judge to decide whether the cited pages establish the ground-truth answer
> (fully / partially / not at all). The same fact often appears in several
> corpus documents — any page that truly establishes it earns credit; there is
> no fixed list of "correct" sources to match against. The
> `ground_truth_sources` in reference_questions.json show where each answer was
> authored from — useful for debugging retrieval, but not the scoring target.
> A citation pointing at a nonexistent file or page counts against you.

## Decisions (confirmed with user)

1. **Penalty** — `citation_accuracy = credit × (valid / cited)` where
   credit = 1.0 / 0.5 / 0.0 for fully / partially / not_at_all.
2. **Judge shape** — one call per question per judge model: all resolved cited
   pages in one prompt; returns overall support label + per-citation labels.
3. **No citations** — score 0.0, counted in the mean (refusals included).
4. **`ground_truth_sources`** — kept as an *unscored* diagnostic
   (`gt_source_hit_rate`), never part of the score.

## Page resolution (no searching)

`{file, page}` → page text, direct lookup:

- `rag.parsing.discover(corpus_dir)` → `rel_path → SourceFile` (with sha256).
- `rag.parsing.cache.ParseCache(cache_dir).load(sha256)` → the cached
  DoclingDocument dict (all 350 corpus PDFs are cached; the cloud node gets
  `corpus/` + `cache/` from the artifacts tarballs).
- `rag.chunking.common.load_docling` + `iter_reading_order` → `(item, page, text)`;
  group by page → the judge sees exactly the text that was indexed
  (tables as Markdown, docling reading order).
- File matching reuses the existing normalized/trailing-suffix path match.
- Page existence is checked against the docling dict's `pages` map.

Invalid-citation reasons (all count as invalid, reported separately):
`unknown_file`, `page_out_of_range`, `missing_page` (PDF cited without a page),
`empty_page` (page exists but parsed to no text), `page_on_txt` (TXT cited with
a page number). TXT files resolve with `page: null` to the whole file text.

## Metric changes

Removed: `citation_recall`, `citation_precision`.
Added: `citation_accuracy`, `full_citation_credit_rate` (accuracy == 1.0),
`invalid_citation_rate`, `uncited_rate`, `gt_source_hit_rate` (diagnostic).
