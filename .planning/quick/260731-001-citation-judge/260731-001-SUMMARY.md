# Summary — LLM-judged citation accuracy

Citation accuracy is no longer exact-matching against `ground_truth_sources`.
Every cited `{file, page}` is now resolved to the **actual corpus page** and an
LLM judge — the same models, retry loop and committee aggregation used for
answer relevance — rules whether the cited pages establish the ground-truth
answer.

    citation_accuracy = credit x (citations resolving to a real page / citations made)
    credit = 1.0 fully | 0.5 partially | 0.0 not_at_all

## What was built

| File | Change |
|------|--------|
| `evalharness/pages.py` | **new** `PageStore`: corpus walk → sha256 → Docling parse cache → page text in reading order. Direct lookup, never a search. Six invalid-citation reasons. |
| `evalharness/prompts.py` | **new** citation-judge system prompt + `build_citation_messages`; page-text budget. Answer-quality prompts now say citations are judged separately (not "by exact matching"). |
| `evalharness/judge.py` | Extracted the shared call/retry/JSON-repair loop; added `judge_citations_one/_all` and `aggregate_citation_committee` (majority + pessimistic tie-break). |
| `evalharness/citations.py` | Rewritten: `resolve_citations`, `score_citations`, and `gt_source_hit` (unscored diagnostic). |
| `evalharness/run.py` | Resolve → citation judge pass → records; `--corpus` / `--cache-dir`. |
| `evalharness/metrics.py`, `report.py` | `citation_accuracy`, `invalid_citation_rate`, `uncited_rate`, `gt_source_hit_rate`; new report section and suggestion rules. |
| `tests/test_evalharness.py` | **new**, 27 tests: page resolution, every invalid reason, score formula, committee, prompt, two end-to-end runs with the judge mocked. |

## Decisions

1. Invalid citations dilute proportionally (`valid / cited`), rather than a
   fixed per-citation penalty.
2. One citation-judge call per question per judge model, showing all resolved
   pages at once — so pages can *jointly* establish a multi-part ground truth —
   returning an overall ruling plus per-citation labels for diagnostics.
3. An answer citing nothing scores 0.0 and counts in the mean, refusals
   included: it establishes nothing.
4. `ground_truth_sources` kept as `gt_source_hit_rate`, explicitly not scored.
5. Only *resolvable* citations reach the judge; invalid ones are penalized
   arithmetically and never shown. A question with nothing resolvable spends no
   judge call.
6. A page that exists but parsed to no text (`empty_page`) counts as invalid but
   is reported under its own reason, so a Docling parse gap stays
   distinguishable from a fabricated reference.

## Verification

- `pytest -m "not slow and not llm"` — 218 passed (27 new).
- Live run, 5 questions, `openai/gpt-oss-120b`: 16 cited pages resolved, 0
  invalid, `citation_accuracy=0.80`. The judge's reasoning quotes the actual
  Hebrew page text (e.g. *"ככלל, הגשת תביעה לגוף מוסדי אינה עוצרת את מרוץ
  ההתיישנות"*), confirming it reads the real document.
- The new definition demonstrably changes results: `dev-01`/`dev-02` cite pages
  other than the authoring sources (`gt_source_hit_rate` 0.0) yet genuinely
  establish the answer — 1.00 under the new metric, 0.00 under the old one.
