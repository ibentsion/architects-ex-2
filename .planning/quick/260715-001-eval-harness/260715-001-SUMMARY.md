# Quick Task 260715-001 — Summary

**Completed:** 2026-07-15

## What was built

`evalharness/` — the Stage 1 evaluation harness:

- **LLM-as-judge** via `tf_client.chat`, pinned to `deepseek-ai/DeepSeek-V4-Pro`
  at temperature 0. Numeric 0–10 grades per category (correctness,
  completeness, conversational quality) plus verdict
  (correct/partially_correct/incorrect/refusal) and a hallucination flag
  (refusals never count as hallucinations). JSON output enforced by prompt with
  parse-and-retry (2 retries feeding the error back).
- **Three judge prompt variants** (`--prompt`): `rubric` (default, anchored
  scales), `strict` (terse fact agreement), `claims` (atomic-claim
  decomposition with supported/contradicted/missing counts).
- **Committee support** (`--judges m1 m2 m3`): median for numeric scores,
  majority vote for categoricals (ties break pessimistic), per-question
  disagreement flags and an overall disagreement rate. Default is one judge.
- **Deterministic citation scoring**: recall over `any_of` source groups
  (file path-suffix match + exact page), precision over cited items. No LLM.
- **Outputs per run**: `judgments.jsonl` (per-question grades + reasoning),
  `metrics.json` (aggregates for programmatic run-over-run comparison),
  `report.md` (English; overall + per-domain/difficulty/source-count tables,
  worst questions, rule-based prioritized improvement suggestions).

## Baseline results (`eval_results/baseline/report.md`)

48/48 judged, zero judge failures. Correctness 4.29/10, completeness 3.71/10,
conversational quality 8.58/10, hallucination rate 0.40, refusal rate 0.02,

evidence-or-abstain policy, investigate travel (0.8/10) and car (2.5/10) domains.
