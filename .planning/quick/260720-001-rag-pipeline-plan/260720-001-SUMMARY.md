## Key decisions

| Decision | Choice | Why |
|---|---|---|
| Vector DB | Qdrant local mode (default); Chroma/Milvus via config | embedded, HNSW, payload filtering |
| Keyword search | in-process bm25s over Stanza lemma+surface tokens; ES/OpenSearch optional | zero infra; FastEmbed sparse BM25 has no Hebrew support |
| Hybrid fusion | own RRF (k=60), not langchain-qdrant HYBRID | Hebrew gap in FastEmbed sparse models |
| Parser | Docling via DoclingDocument JSON (never Markdown-intermediate) | Markdown export destroys `prov.page_no`; citations need pages |
| RTL safety | blocking canary-word extraction gate at ingestion start | docling RTL issues still open; top project risk |
| Embeddings | BAAI/bge-m3 default; e5-large / Webiks alternatives | MIT license, 1024d, best Hebrew stability |
| Reranker + gate | bge-reranker-v2-m3, sigmoid ≥ 0.35 relevance gate | Apache-2.0; jina-reranker is CC-BY-NC (config option w/ warning) |
| Hebrew NLP | Stanza (`iahltwiki` package) default; trankit/YAP same interface | pip-installable, best modern-Hebrew lemmas |
| Fallback | "אין לי מספיק מידע" path skips LLM when gate rejects all | refusal beats hallucination per exercise grading |
